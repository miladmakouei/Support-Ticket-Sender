# Support Ticket Sender

یک برنامه ساده با Python برای ارسال درخواست‌های پشتیبانی به یک API.

در این پروژه کاربر اطلاعاتی مانند نام، عنوان درخواست، دسته‌بندی و توضیحات مشکل را وارد می‌کند. برنامه اطلاعات را به فرمت JSON تبدیل کرده و با استفاده از HTTP POST به API ارسال می‌کند.

## امکانات

- دریافت اطلاعات مشتری از ورودی
- دریافت عنوان و توضیحات درخواست
- تعیین دسته‌بندی درخواست
- تبدیل اطلاعات به JSON
- ارسال اطلاعات با HTTP POST
- دریافت و نمایش پاسخ API
- مدیریت خطاهای ارتباطی و پاسخ سرور

## ابزارهای استفاده‌شده

- Python 3
- `urllib.request`
- `urllib.error`
- `json`
- HTTP POST
- JSON

## پیش‌نیازها

- نصب Python 3
- اتصال به اینترنت

این پروژه فقط از کتابخانه‌های داخلی Python استفاده می‌کند و نیازی به نصب پکیج خارجی ندارد.

## روش اجرا

ابتدا مخزن را دریافت کنید:

```bash
git clone https://github.com/USERNAME/python-support-ticket-sender.git
```

وارد پوشه پروژه شوید:

```bash
cd python-support-ticket-sender
```

برنامه را اجرا کنید:

```bash
python3 main.py
```

## درباره API آزمایشی

برای تمرین ارسال اطلاعات از سرویس JSONPlaceholder استفاده شده است.

این سرویس درخواست POST را دریافت می‌کند و یک پاسخ آزمایشی برمی‌گرداند. اطلاعات ارسال‌شده به‌صورت دائمی ذخیره نمی‌شوند.

هدف این پروژه تمرین ارسال اطلاعات از Python به سرویس‌های خارجی، کار با JSON، آشنایی با HTTP POST و مدیریت پاسخ API است.
